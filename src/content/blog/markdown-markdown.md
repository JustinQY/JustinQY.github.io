总结了常用的markdown语法, 方便平常整理笔记时使用~~


### 标题

---

使用 # 号表示标题，支持 1 到 6 级标题。
```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

### 段落

---

段落之间需要空一行。
```markdown
这是一个段落。

这是另一个段落。
```

### 强调

---

使用 * 或 _ 表示斜体，使用 ** 或 __ 表示粗体。
```markdown
*斜体*
_斜体_
**粗体**
__粗体__
```

### 删除线

---

使用 ~~ 表示删除线。
```markdown
~~删除线~~
```

### 引用

---

使用 > 表示引用。
```markdown
> 这是一个引用。
```

### 列表

---

#### 无序列表
使用 -、* 或 + 表示无序列表。
```markdown
- 项目一
- 项目二
  - 子项目
  - 子项目

* 项目一
* 项目二

+ 项目一
+ 项目二
```

#### 有序列表
使用数字加点表示有序列表。
```markdown
1. 项目一
2. 项目二
   1. 子项目
   2. 子项目
```

### 链接

---

使用 [显示文本](链接地址) 表示链接。
```markdown
[Google](https://www.google.com)
```

### 图片

---

使用 `![替代文本](图片地址)` 插入图片。
```markdown
![描述](https://www.example.com/image.jpg)
```

### 代码

---

#### 行内代码
使用反引号 ` 表示行内代码。
```markdown
这是 `inline code`。
```

#### 代码块
使用三个反引号   ``` 或四个空格表示代码块。
```markdown
// ```javascript
// console.log('Hello, world!');
// ```
```

### 公式

---

#### 行内公式
```markdown
$f_{w,b}(x) = wx + b$
```

#### 块级公式
```markdown
$$
f_{w,b}(x) = wx + b
$$
```


### 表格

---

使用 `|` 和 `-` 创建表格。
```markdown
| 标题一 | 标题二 |
| ------ | ------ |
| 单元格  | 单元格  |
| 单元格  | 单元格  |
```

### 水平线

---

使用三个及以上的 -、* 或 _ 表示水平线。
```markdown
---
***
___
```

### 注脚

---

使用 [^注脚] 表示注脚。
```markdown
这是一个带注脚的文本[^1]。

[^1]: 这是注脚内容。
```

### 任务列表

---

使用 - [ ] 表示未完成任务，- [x] 表示已完成任务。
```markdown
- [x] 已完成任务
- [ ] 未完成任务
```

### 转义

---

使用反斜杠 \ 转义特殊字符。
```markdown
\*这个文本没有被强调\*
```
